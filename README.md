# legend-media

Audio and video files for **The Legend of D&C** (Echo Valley school songs, music videos, Counting Woods, the Chronicle theme).

The files live as **GitHub Release assets** (not in git history), so they cost nothing to store or serve and never count against the app's Vercel or Supabase quotas. The app links to:

    https://github.com/cynthiamoon7-moon/legend-media/releases/download/<tag>/<file>

Tags: `media-2026-10` — first move from Supabase Storage (2026-10-14).

Sources (lyrics, Suno logs, production notes) are in the private `legend-music` project.
